Activation codes

How do I enter the code?

Tap the link in our e‑mail on the phone where Call'em is installed — the app opens and confirms activation. Or open Settings → Call'em Pro → I have an activation code and paste the code.

The app says the code is for a different phone

Codes are tied to the phone code we signed. Open the Pro screen, tap the phone code to copy it and send it to us again — we will issue a new code free of charge.

I got a new phone

Set up the new phone with Copy from another phone (or Settings → Other phones on the old one): places, people and Pro move together. If the old phone is lost, write to us with the new phone code.

Does Pro need internet or an account?

No. The code is checked on the phone itself and stored there. Nothing about the purchase is sent to our server.

How is the code protected?

The code is a digital signature of your phone code, made with our private key. The app verifies it with the matching public key built into it — so a code can't be guessed or altered, and a code for one phone doesn't work on another.
